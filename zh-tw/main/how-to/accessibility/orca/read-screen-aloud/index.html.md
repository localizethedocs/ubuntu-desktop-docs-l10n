# Read the screen aloud

You can enable the Orca screen reader, which speaks the user interface.

To learn its basic control, go to [Get started with the screen reader](../../../tutorial/get-started-with-the-screen-reader.md#get-started-with-the-screen-reader).

#### NOTE
Ubuntu Desktop might present some challenges when using the screen reader. If you experience difficulty, refer to [Improve screen reader usability](../../troubleshoot/improve-screen-reader-usability.md#improve-screen-reader-usability).

1. Start Orca:

   ### With a keyboard shortcut

   Press `Super+Alt+S`.

   You can also use this shortcut at the login screen.

   ### In the accessibility menu

   In the [accessibility menu](../find-the-accessibility-menu.md#find-the-accessibility-menu) in the top bar, select Screen Reader.

   You can also use this menu at the login screen.

   ### Using Settings

   1. Open the Activities overview and start typing **accessibility**.
   2. Click Accessibility to open the panel.
   3. Open the Seeing section.
   4. Enable the Screen Reader option.
2. Listen to the Orca help. Orca tells you its version and gives you pointers on how to use the screen reader:

   ### Laptop layout

   `CapsLock+H`

   ### Desktop layout

   `Insert+H`

   To exit help mode, press `Esc`.
3. If you use Firefox, close it and reopen it. Orca can then read the browser content.

The screen reader stays active the next time that you log in.

## Installing the screen reader

Orca is installed by default on Ubuntu Desktop. If you’re using a custom desktop or package set, Orca might not be installed. Install it using the following command:

`$ ``sudo apt install orca`
