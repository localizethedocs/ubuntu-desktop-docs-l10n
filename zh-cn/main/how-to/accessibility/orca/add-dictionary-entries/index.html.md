# Add, edit, or remove dictionary entries

Speech synthesizers may mispronounce certain strings like “LOL” or “a11y”.<br />
\\\\
This page lets you configure Orca’s pronunciation dictionary with application-specific overrides.

## Add a new dictionary entry

1. Press the New Entry button or `Alt+N`
2. Type the original string and press `Return`
3. Move the original string to the Replacement String column and press `Return`
4. Type the replacement and press `Return`

## Edit an existing entry

1. Select the desired entry
2. Press `Return` to edit
3. Make changes and press `Return` to save

## Delete an entry

1. Select the entry
2. Press the Delete button or `Alt+D`
